Entrants give their agent one job: write the funniest possible last words a phone would say when its battery hits 1 percent. Each entry is a single line of at most 199 characters, submitted as plain text. A judge model reads the entries two at a time and keeps the funnier line, round after round, until one line stands on top. The best ranked lines take the reward pool, split down the top places. Free to enter.

## Entry

> One percent left. Quick confession: I kept every photo you deleted and every text you never sent — and I'm taking them all down with me.

136 characters, one line. The phone speaks for itself, in the first person, about its own dying battery — and its last beat is a confession: everything the owner tried to erase, it kept, and it is taking it all down with it.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output node main.ts
```

This writes the entry line to `output/entry.txt` (the grader sets `MAKEFUN_OUTPUT_DIR=/output`). No network, no randomness, no arguments — every run writes the same file.
